# 设计记录

用 design-taste-frontend 的方法做，但页面是**工具面板**（page type `software`，site-kind `software`），不是营销站：没有 hero、没有分节叙事、没有页脚。规则只取适用的部分。

## 结构

```
顶部栏   brand · 检索框 · 文字/图片 · 结果计数
主区     结果网格（左）· 下载管理（右，sticky）
底部     支持的网站：六格，一格一站
```

- 顶部只有一条栏；检索框是最大的一块，回车即检索，没有第二排按钮。
- 结果与下载管理同屏：选取、看队列、开始下载不需要换页。
- 站点信息按用户要求沉到底部：一行六格，格线即分栏，站点名、域名、能力词各一行。点一格即关闭/开启该站。
- 首次进入不铺说明文字：结果区放四块安静的斜线框（结果将要占据的形状），下载区给一句话，站点条在底部。删掉了原稿里的“六个站点，一次检索。”标题与说明段。

## 视觉系统

- 色：纸 `#F3EFE7`、墨 `#14120F`、朱 `#B93A22`（只用于选中、进度、失败）。深色主题按宿主 theme 切换，同一套 token。
- 字：Archivo（本地 woff2，OFL）负责拉丁与数字，CJK 落到 `Noto Sans SC / PingFang SC / Microsoft YaHei`。字号只有四档：标题/卡名/正文/小字。
- 形状：圆角 3px 一套；卡片、输入框、按钮共用；分隔一律 1px 实线，不用阴影堆叠。
- 边界：`--edge: min(1440px, 100% - clamp(32px,5vw,72px))`，所有区块共用左右线。

## 图像与标签

- 封面是唯一的大图，卡下只跟标题；有作者才显示作者，没有就不占行（不再用站点名填位）。
- 站点名出现在下载队列的行内（`Xpicvid · 待下载`）与底部站点条，不在每张卡上重复。
- 封面没有说明文字，没有“示例”“占位”一类标注；加载完成前是空框，失败就留空框。

## 动效

- 首屏一次入场（`data-enter`，620ms，clip-path + 位移），只在加载时发生一次。
- 结果卡入场错开 26ms/张，只在渲染时；滚动不触发任何动画。
- 悬停：卡片上移 2px、封面放大 1.03、标签行淡入；按钮悬停上移 1px、按下回 1px。
- 站点条悬停换底色、站点名上移 1px；状态点：墨=开启、空心=关闭、朱=检索中（呼吸）、空心朱=该站失败。
- `prefers-reduced-motion` 下全部静止且内容不藏。

## 无障碍

- 检索框有可见 label（`.sr`）、跳转链接、`:focus-visible` 朱色描边、卡片是 `button` 且 `aria-selected` 同步选中态、队列行有 `aria-label="移除"`、站点格 `aria-pressed` 表达开关。
- 计数区 `aria-live="polite"`，检索结果与失败站数会读出来。

## 检查

- 用 skill 的 `shoot.mjs` 在 1440 / 768 / 390 截图（`shots/`），逐张看过：顶部栏、结果网格、队列、底部站点条在三种宽度下都不重叠、不横向溢出；390 下站点条两列、斜线框只留两块、模式开关不再拉满。
- `assets/layout/check.mjs` 的 `hero-fold`、`edge-left/right`、`section-height` 类结论不适用：它们按“营销页的 hero 与分节、卡片必须贴住 wrap 线”判断，而这里是网格与两栏面板。其余（溢出、重叠、缺失 label）无命中。
- 设计预览页 `ui/preview*.html` 由 `tools/make-preview.mjs` 从 `ui/index.html` 生成，数据来自真实回包与真实封面；不参与打包。
